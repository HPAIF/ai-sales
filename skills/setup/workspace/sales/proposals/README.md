# Proposals

One file per proposal: `PP-XXXX-account-slug.md`, from the plugin's `templates/proposal.md`,
with the same statuses as drafts (`draft` / `ready` / `approved` / `sent` / `dropped`).

Prices, discounts and terms come only from founder decisions (`history/decisions.md`) or the
product file; anything else stays as `[PRICE — founder to decide]` / `[TERM — founder to
decide]`. The founder sends the proposal. Never delete a proposal; change its status and add a
new version (`PP-XXXX-…-v2.md`).
